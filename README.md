# Gandalf (OpenClaw Workspace) This repo is the operational brain for Gandalf: prompts, policies, skills, and—most importantly—Receipts. ## What is a Receipt? A Receipt is a verifiable proof that an agent action happened: - what it tried to do - what changed - links to artifacts (PR, commit, file, log) - status + timestamps Receipts are how we keep agents trustworthy.
cat > receipts/templates/receipt.md <<'EOF' # Receipt: <action-title> **id:** <uuid-or-timestamp> **actor:** Gandalf **requested-by:** Elladan **timestamp (EET):** <yyyy-mm-dd hh:mm> **status:** <success|failed|partial> ## Intent <one sentence> ## Plan - [ ] Step 1 - [ ] Step 2 - [ ] Step 3 ## Changes / Artifacts - PR: <link> - Commit: <hash> - Files changed: - <path> - Notes: - <anything important> ## Verification How a human can verify quickly: - command(s) to run - what output should look like ## Risks / Rollback - what could go wrong - how to undo EOF
